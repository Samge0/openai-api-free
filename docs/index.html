常见问题

快速了解 ChatGPT 账号轮询服务的常见疑问

如何配置多个 OpenAI 账号？

在 config.json 中配置 account_infos 或 account_infos_api。格式为："邮箱|密码|代理IP"，代理IP为可选项。例如：

"samgeapp@gmail.com|password|http://127.0.0.1:7890"
免费账户和 Plus 账户有什么区别？

免费账户每小时限制 50 个请求，Plus 账户每小时限制约 150 个请求。通过多账户轮询，可以突破单个账户的限制。

如何选择账号切换模式？

在 config.json 中设置 account_switching_type 参数：

  • asc - 正序切换，按列表顺序依次使用
  • random - 随机切换，随机选择可用账户
代理服务器是什么意思？

代理服务器用于隐藏真实 IP 地址，避免 OpenAI 检测到多账户来自同一 IP。每个 IP 每 10 秒限制 15 个请求，使用不同代理可以绕过此限制。

如何调试 API 接口？

配置 http-client.env.json 文件，然后在 test_main.http 中进行接口调试。确保 auth_token 与 config.json 中的一致。
